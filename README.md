# Alaska-Fast-Fix-Schedule-Software
A project I was paid to make for Alaska Fast Fix. It's purpose is to manage schedules through a basic admin-user interface.

# Principles:
The project should have these things; they are non-negotiable:
 - This system would be built with Zero Trust principles in mind. Only the admin, or super user, should be able to add, remove, or modify the schedule.
 - Support for a ticketing system that would allow users to claim jobs from tickets and write notes when finished.
